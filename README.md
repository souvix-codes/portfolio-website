# Portfolio Website Template

A modern, responsive portfolio website template built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Easy to Customize**: Simple structure makes it easy to personalize
- **Contact Form**: Functional contact form with validation
- **SEO Friendly**: Proper semantic HTML structure
- **Dark Navigation**: Professional navbar with mobile hamburger menu
- **Project Showcase**: Display your portfolio projects with images and links
- **Skills Section**: Highlight your technical skills
- **Social Links**: Quick access to your social media profiles

## Sections

1. **Navigation Bar**: Fixed navbar with smooth scrolling links
2. **Hero Section**: Eye-catching introduction with call-to-action button
3. **About Section**: Personal introduction and key information
4. **Projects Section**: Showcase your best work with descriptions and links
5. **Skills Section**: Categorized list of technical skills
6. **Contact Section**: Contact information and message form
7. **Footer**: Copyright and attribution

## Customization

### 1. Personal Information
Update the following in `index.html`:
- Name in the hero section and navbar
- Contact email and phone number
- Location and other personal details
- Social media links

### 2. Projects
Replace project cards with your own:
- Update project titles, descriptions, and technologies
- Replace placeholder images
- Update GitHub and live demo links

### 3. Skills
Modify the skills listed in the Skills section to match your expertise

### 4. Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --text-color: #333;
    --light-text: #666;
    --background: #f9fafc;
    --white: #fff;
    --border-color: #e0e0e0;
}
```

### 5. Images
Replace placeholder images:
- Profile photo (Hero section)
- About section image
- Project screenshots

## Tips for Best Results

1. Use high-quality images for projects (at least 600x400px)
2. Keep project descriptions concise and impactful
3. Update all placeholder text with your actual information
4. Test on mobile devices before deploying
5. Use real links for social media and project repositories
6. Consider adding a personal logo or custom favicon
